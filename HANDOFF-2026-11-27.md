# Handoff — 27 Nov 2026

Where the work stands, and how to pick it up on another computer. The same file is in all four repos.

## Repos and branches

| Repo | Branch | What it is |
|---|---|---|
| `education-ai` | `feat/gemini` | FastAPI AI service (Gemini). Every AI call lives here. |
| `education-backend` | `feat/book-avatar` | NestJS API (Postgres, Redis/BullMQ). No AI runs here, only retrieval. |
| `education-frontend` | `feat/live` | Next.js web app (API mode by default). |
| `education-flutter` | `feat/api-integration` | Flutter app. |

Clone all four side by side in one folder, then check out the branches above.

## Secrets (not in git)

`.env` files are gitignored. Copy them from the old PC, or create them from `.env.example`:

- `education-ai/.env`:
  - `AI_LLM=gemini`
  - `GEMINI_API_KEY`
  - `AI_SERVICE_KEY` (≥32 characters; must equal the backend's key)
- `education-backend/.env`:
  - `DATABASE_URL`
  - Redis settings (`REDIS_DB=8`)
  - `AI_PROVIDER=service`
  - `AI_SERVICE_URL=http://localhost:8100`
  - `AI_SERVICE_KEY` (same as above)
  - `EMAIL_PROVIDER=resend`
  - `RESEND_API_KEY`
  - `PAYMENT_PROVIDER=manual`
  - `AUTH_DEMO_MODE=true` (local only)
  - `SEED_ON_EMPTY=true`
- `education-frontend/.env.local`: `NEXT_PUBLIC_API_URL=http://localhost:4000/api/v1` (see `.env.example`).

## Run locally

```bash
# Postgres 16 and Redis must be running
cd education-ai && uv sync && uv run python -m uvicorn app.main:app --port 8100
cd education-backend && npm i && npm run prisma:generate && npx prisma migrate deploy && npm run build && node dist/main.js
cd education-frontend && npm i && npm run dev -- -p 3001
```

## Done today (simulated → live)

- **Real NCTB textbooks.**
  - Sources: the official 2026 Class 9–10 Bangla-version PDFs (Physics, Chemistry, Biology, General Maths, Higher Maths) on nctb.gov.bd.
  - Download and ingest them with `education-backend/scripts/ingest-nctb.sh`.
  - The PDFs have no text layer, so Gemini vision reads every page, 4 pages per request.
  - Copyright belongs to NCTB. Check its terms before any commercial use.
- **Book ingestion pipeline** (`education-backend/src/modules/document-processing/ingestion.service.ts`):
  - Stages: validate → extract → map chapters → chunk → embed → index → quality check → review → publish.
  - Extracted pages are stored in `bookPages`.
  - The real passages replace the book's synthetic ones.
  - Vectors are kept in `kbVectors`.
  - A failed stage can be retried; extraction resumes after the pages already read.
- **Retrieval.** `src/domain/retrieval.ts` is hybrid search (keyword + embeddings). The tutor and the book avatar use it; the avatar uses the real pages of ingested books. Passages without vectors are embedded in the background at startup.
- **New AI service endpoints:**
  - `/v1/documents/extract`, `/v1/documents/questions`, `/v1/documents/chapters`
  - `/v1/grade`
  - `/v1/english/pronunciation`
  - `/v1/study/plan`
  - Flashcards also accept `source_text`
- **New backend endpoints:**
  - Books and documents: `GET /books/:id/pages/:n`, `GET /books/:id/search`, `POST /document-text`, `POST /questions/extract`
  - Study AI: `POST /english/:sid/pronunciation`, `POST /planner/:sid/generate`
  - Social: `/leaderboard`, `/challenges` (and its sub-routes)
  - Account: `POST /auth/change-password`, `GET` and `DELETE /auth/sessions`, `POST /auth/two-factor` (login then asks for an OTP), `POST /users/me/tickets`
  - Guardian and admin: `POST /guardian/report-email`, `GET /analytics/breakdowns`, `POST /kb/collections/:id/reindex`
  - Public: `GET /shared/:linkId`
  - An admin invite (a user created with `status: invited`) now sends a Resend email.
  - The AI marks written exam answers on submit; the keyword estimate is only a fallback.
- **Web:**
  - Real book pages in the reader.
  - Admin book upload and version replace go to the server.
  - AI question import and board-paper OCR.
  - Notes from the text of an uploaded file.
  - AI grading labels on exam results.
  - Recorded pronunciation scoring, and an AI-assessed speaking exam.
  - AI planner and AI flashcards from notes or chats.
  - Live leaderboard and challenges (`components/student/achievements/social-live.tsx`).
  - Password, 2FA and session settings.
  - Help tickets and feedback.
  - Parent report email.
  - Real teacher invitations.
